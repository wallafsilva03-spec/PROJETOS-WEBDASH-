Arquitetura

Sem servidor próprio: o frontend conversa diretamente com o Supabase, e toda a regra de negócio e de acesso vive no banco.

Frontend

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS · shadcn/ui sobre Radix · Framer Motion · TanStack Query · React Hook Form · Zod · dnd-kit · Recharts · date-fns.

Backend — só Supabase

PostgreSQL · Authentication · Realtime · Storage · Row Level Security · Database Functions · Triggers · Views. Nenhum Node, Nest ou Express no caminho.

Inteligência que roda dentro do banco

Progresso ponderado

Um trigger recalcula o percentual do projeto a cada mudança de tarefa, ponderando pelas horas estimadas de cada uma.

Saúde automática

O previsto para hoje é medido em dias úteis do cronograma; o desvio contra o executado classifica o projeto como adiantado, no prazo, em risco, atrasado ou crítico.

Cronograma que se ajusta

Adiar uma tarefa empurra as sucessoras conforme o tipo de dependência e a folga, preservando a duração e com proteção contra ciclos.

Instalação

Do clone ao primeiro login em cinco passos.

  1. Instale as dependências

    Node 20 ou superior.

    npm install
  2. Crie o projeto no Supabase

    Copie a URL e a chave anônima em Project Settings → API para o arquivo de ambiente.

    cp .env.example .env.local
  3. Aplique as migrations

    Na ordem numérica, pelo CLI ou colando no SQL Editor do painel.

    supabase link --project-ref SEU-PROJECT-REF
supabase db push
  4. Rode a aplicação

    O primeiro usuário que se cadastrar vira administrador automaticamente.

    npm run dev
  5. Opcional: massa de demonstração

    Já logado, execute no SQL Editor para criar projetos, tarefas, marcos e riscos de exemplo.

    select public.seed_demo_projects();
